# QnA Chatbot with LangChain + Ollama + Streamlit

Local AI Chatbot - 100% Free & Private - No API Key Needed

## Tech Stack
- LangChain
- Ollama (Llama 3.2)
- Streamlit

## How to Run
1. Install Ollama from ollama.com
2. ollama pull llama3.2
3. pip install -r requirements.txt
4. Terminal 1: ollama run llama3.2
5. Terminal 2: streamlit run app.py
